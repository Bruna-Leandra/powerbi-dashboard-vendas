# Dashboard de Vendas - Power BI

Este projeto apresenta um painel interativo criado no Power BI com base em dados fictícios de vendas.

## 🧩 Funcionalidades
- Visualização de KPIs: faturamento total, ticket médio e vendas por região
- Filtros dinâmicos por data, categoria e produto
- Segmentações com gráficos de barras, linhas e pizza
- Layout otimizado para tomada de decisão rápida

## 🛠️ Ferramentas utilizadas
- Power BI Desktop
- Excel (base de dados)

## 🎯 Objetivo
Praticar a construção de dashboards que traduzem dados brutos em insights visuais claros e acionáveis.
